# 🪐 Orbit Hop

Ein schnelles Arcade-Spiel für Browser und Handy: Spring von Planet zu Planet, ziel auf die Mitte und jag deinen Rekord. Nur noch eine Runde …

## So wird gespielt

- **Tippen / Klicken / Leertaste** – dein Komet löst sich aus der Umlaufbahn und fliegt geradeaus weiter.
- Triff die Umlaufbahn eines anderen Planeten, um dort zu landen.
- Ziel auf die **Mitte** des Planeten für **PERFEKT**-Landungen – jede Perfekte in Folge gibt mehr Punkte.
- Fliegst du ins Leere, ist die Runde vorbei.

### Gefahren
- **Wandernde Planeten** bewegen sich hin und her.
- **Rote Planeten mit „!“** zerfallen nach ein paar Sekunden – schnell weiter!
- Je höher du kommst, desto schneller wird alles.

### Fortschritt
- 🪙 **Münzen** sammeln und **8 Skins** freischalten (Feuerball, Schwarzes Loch, Regenbogen …)
- **Missionen**, die mit jedem Erfolg schwieriger werden und mehr Münzen bringen
- Rekord, Münzen und Skins werden im Browser gespeichert

## Lokal spielen

Einfach `index.html` im Browser öffnen. Keine Installation, keine Abhängigkeiten.

## Auf GitHub Pages veröffentlichen

1. Repository auf GitHub pushen.
2. Auf GitHub: **Settings → Pages → Branch: `main` / Ordner: `/ (root)`** → Speichern.
3. Nach einer Minute läuft das Spiel unter `https://<dein-name>.github.io/orbit-hop/`.
